# Metis · 抖音和小红书创作者知识库

简体中文 · [English](README.en.md)

**持续学习你关注的抖音博主和小红书创作者，把他们视频和图文里的做法用到自己的项目里。**

你可以按创作者积累作品。Metis 分析视频里的讲解和画面，以及图文里的文字和图片，整理出作者讲了什么、用了哪些方法、有哪些例子。知识条目保留作品出处和解析依据，方便你日后回查。

收藏和学习可以跨不同账号、主题和内容形式。遇到实际问题时，你可以按关键词或问题找回学过的内容，比较不同创作者的观点和做法，再查原作品判断哪些适合用在手头的任务里。

## 打开 Metis 后怎么用

1. **作品资料库**。按创作者查看积累下来的作品，也可以点「手动导入素材」添加有权使用的视频、图片或文字。
2. **学习进度**。查看哪些作品还在处理，哪些已经学完，失败时查看原因。
3. **AI 知识中心**。按关键词或问题找学过的内容。想判断一条结论靠不靠谱，可以顺着引用看对应的作品和依据。

## 下载 Windows 预览版

[下载 Windows x64 便携包](https://github.com/553574842-sys/metis/releases/download/v0.1.0-preview/Metis-Windows-x64.zip)

1. 把 ZIP 完整解压到你有写入权限的文件夹。
2. 双击 `Metis.cmd`，等浏览器自动打开。
3. 先打开一份示例作品，再到「AI 知识中心」搜作品里的关键词，试着从知识条目回到作品。

首启会创建本地资料库和虚构示例。示例可以离线体验，无需注册或填密钥。使用中请保留启动窗口。关闭窗口会停止服务，下次从同一文件夹启动，可以继续使用已有资料。

## 学习自己的抖音和小红书素材

当前 Windows 预览版通过「手动导入素材」添加抖音视频、小红书图文或其他本地资料。有原作品链接的话，可以随素材一起填写。**贴链接自动采集和神经元脑图需要另行接入。**

要用 AI 分析自己的素材，先启动一次 Metis，再关闭启动窗口。打开解压目录生成的 `.env`，参照同目录的 `.env.example` 填写模型服务、模型名和密钥，将 `CLOUD_CALLS_ENABLED` 设为 `true`，然后重新启动。分析时，待处理内容会发给你配置的模型服务，费用按该服务计费。

## 资料和配置存在哪里

程序把知识和素材保存在解压目录的 `data/`，把本机配置保存在 `.env` 和 `.env.local`。备份或迁移前先退出程序。发布包内只有程序、运行依赖和虚构示例。

随包许可和构建说明见 `python/LICENSE.txt`、`ffmpeg/LICENSE` 和 `ffmpeg/README.txt`。

### 从源码启动

准备 Python 3.12、Node.js、FFmpeg，并将它们加入 PATH。在 Windows PowerShell 中进入仓库根目录，执行：

```powershell
.\scripts\init.ps1 -Demo
.\scripts\start.ps1
```

打开 [本机工作台](http://127.0.0.1:8000)。日常体验可直接使用上面的 Windows 便携包。
