# Metis · 创作者知识库

Metis 把创作者的作品拆解成带出处、可检索的知识，方便你把学到的方法用到自己的项目里。

[下载 Windows x64 便携版](../../releases/latest/download/Metis-Windows-x64.zip)

## Windows x64 快速开始

1. 将 ZIP 完整解压到一个你可以写入的文件夹。
2. 双击 `Metis.cmd`。首次启动会在该文件夹内创建独立知识库，并导入虚构示例。
3. 浏览器会打开本机工作台。可以先在「作品资料库」看示例，再到「AI 知识中心」检索并回查出处。

便携包自带 Python、前端和 FFmpeg。日常使用时保留启动窗口，关闭启动窗口即可停止后台。下次双击同一个文件会读取现有数据。本机服务只监听回环地址。演示可以离线使用。

## 使用自己的资料

通过「作品资料库」导入你有权使用的文字、图片或视频。默认是 Mock 演示模式。要运行真实 AI 分析，首次启动后关闭程序，参考 `.env.example` 在同目录生成的 `.env` 中配置自己的模型服务、模型名和密钥，再将 `CLOUD_CALLS_ENABLED` 设为 `true` 并重新启动。模型服务可能收费，开启后分析资料会发给你配置的服务。自动平台采集和神经元脑图属于独立接入能力。

## 数据

下载包只带虚构示例。首次启动生成的 `data/`、`.env` 和 `.env.local` 属于这份安装。迁移或备份前先关闭程序，并妥善保管本机数据和密钥。

Python 及 FFmpeg 的随附许可和构建说明分别位于 `python/LICENSE.txt`、`ffmpeg/LICENSE` 和 `ffmpeg/README.txt`。
