# Metis · 创作者知识库

**把看过的视频和图文，变成下次做项目时能搜到、能回看、能用上的案例。**

比如你收藏过几篇 Logo 图集。轮到自己做品牌时，你想找的是「哪些案例用留白让两个形状产生联系」。把有权使用的图片或视频导入 Metis，配置 AI 后，它可以整理作品里的方法和例子。下次按问题搜索，找到相关笔记，再回到作品详情核对图片或解析依据，决定哪一招能用到自己的方案里。

Metis 里主要用三个地方：

- **作品资料库**保存你导入的文字、图片和视频，也能查看每份作品的解析结果和处理状态。
- **AI 知识中心**按主题、关键词或问题找笔记。看到有用的结论，可以顺着引用回到相关作品。
- **学习进度**用来看哪些内容还在处理、哪些已经入库，以及哪里需要重试。

## 先用示例体验

1. [下载 Windows x64 便携包](https://github.com/553574842-sys/metis/releases/download/v0.1.0-preview/Metis-Windows-x64.zip)，把整个 ZIP 解压到一个可写入的文件夹。
2. 双击解压目录里的 `Metis.cmd`。首次启动会创建本机资料库并打开浏览器。
3. 到「作品资料库」打开一份示例，再到「AI 知识中心」搜示例里的关键词，点进结果看它对应的作品和原文依据。

示例是虚构数据，可以离线体验，无需注册或填写 AI 密钥。使用时保留启动窗口，关闭窗口会停止本机服务。下次从同一文件夹启动，可以继续使用已经保存的资料。

## 用自己的素材

1. 首次启动后退出 Metis。打开解压目录里刚生成的 `.env`，按 `.env.example` 填入自己的 AI 服务、模型和密钥，将 `CLOUD_CALLS_ENABLED` 设为 `true`，再启动。
2. 在「作品资料库」点「手动导入素材」，选择有权使用的文字、图片或视频。手头有原作品链接时，可以随素材一起填写，方便日后回查。
3. 在「学习进度」看处理状态。成功后去「AI 知识中心」按你正在做的事搜索，再打开引用核对出处。

当前下载版的主要入口是**手动导入**。抖音、小红书链接自动采集和神经元脑图需要另外接入。真实 AI 分析会将待处理内容发给你配置的服务，费用按该服务计费。

## 数据放在哪里

知识和素材保存在解压目录的 `data/` 中，配置和密钥在 `.env` 与 `.env.local`。备份或迁移前先关闭 Metis。发布包里的内容是程序和虚构示例。

随包许可和构建说明见 `python/LICENSE.txt`、`ffmpeg/LICENSE` 和 `ffmpeg/README.txt`。
